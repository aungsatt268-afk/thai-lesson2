ထိုင်းစာ လေ့ကျင့်ခန်းများ (သင်ခန်းစာ ၁ - ၂၀)

အပိုင်း (၁) - ဖတ်ရန် လေ့ကျင့်ခန်း (Reading Exercise)

၁.၁ စာပိုဒ်ဖတ်ခြင်း (Buying Food & Daily Life)

สวัสดีครับ/ค่ะ
วันนี้ ตอน บ่ายสองโมง ผม/ดิฉัน ไป ร้านอาหาร
สั่ง ข้าวผัดไก่ หนึ่ง จาน และ ต้มยำกุ้ง ไม่ ใส่ พริก
อาหาร อร่อย มาก ทั้งหมด ราคา หนึ่งร้อยสี่สิบบาท
ตอนเย็น อยาก ไป ร้านขายยา ซื้อ ยาแก้ไอ
พรุ่งนี้ วันเสาร์ เป็น วันหยุด จะ เข้านอน สี่ทุ่ม ครับ/ค่ะ

၁.၂ ဝါကျတိုများ ဖတ်ခြင်း (Short Sentences)

  1. เมื่อวานนี้ ผม ไป ทำงาน ตอน แปดโมงเช้า
  2. คุณ ชอบ เสื้อ สีแดง หรือ สีชมพู มากกว่า
  3. ขอ น้ำเปล่า สอง แก้ว และ ของทานเล่น ด้วย ครับ/ค่ะ
  4. เขา เป็น หมอ อยู่ ที่ โรงพยาบาล ใน กรุงเทพฯ
  5. สัปดาห์หน้า วันพุธ เป็น วันเกิด ของ แม่

အပိုင်း (၂) - ရေးရန် လေ့ကျင့်ခန်း (Writing Exercise)

၂.၁ မြန်မာမှ ထိုင်းသို့ ဘာသာပြန်ရန်

  1. ၂၇၅ (ကိန်းဂဏန်း)
  2. နေ့လည် ၁ နာရီ
  3. ည ၉ နာရီ
  4. ဒီနေ့ ငါ မအားဘူး၊ အလုပ် အရမ်းရှုပ်တယ်။
  5. ကြက်ဆီထမင်း တစ်ပန်းကန်နဲ့ ရေတစ်ခွက် ပေးပါ။
  6. ဒီအင်္ကျီ အရမ်းဈေးကြီးတယ်၊ လျှော့ပေးလို့ ရမလား။
  7. နင် ဘာအရောင် အကြိုက်ဆုံးလဲ။
  8. မနေ့က သွားကိုက်လို့ ဆေးဆိုင်သွားခဲ့တယ်။
  9. နက်ဖြန် ပိတ်ရက် မဟုတ်လား။
  10. သန့်စင်ခန်း ဘယ်နားမှာလဲ။

၂.၂ ကွက်လပ်ဖြည့် လေ့ကျင့်ခန်း

  1. ตอนเช้า เขา ...... นอน ตอน ตีห้า (ตื่น / กิน / ซื้อ)
  2. ขอ สั่ง ก๋วยเตี๋ยว หนึ่ง ...... (แก้ว / จาน / ชาม)
  3. วันนี้ วันศุกร์ พรุ่งนี้ วัน ...... (เสาร์ / อาทิตย์ / จันทร์)
  4. อาหาร จานนี้ ...... มาก ไม่ เผ็ด เลย (อร่อย / ยาก / ยาว)
  5. เขา มี อาการ ...... คอ (เจ็บ / ขาว / สูง)

အပိုင်း (၃) - အဖြေမှန်များ (Answer Key)

အဖြေ (၁.၁) စာပိုဒ် ဘာသာပြန်အဓိပ္ပာယ်:
မင်္ဂလာပါ။ ဒီနေ့ နေ့လည် ၂ နာရီမှာ ကျွန်တော်/ကျွန်မ စားသောက်ဆိုင် သွားခဲ့ပါတယ်။ ကြက်သားထမင်းကြော် တစ်ပန်းကန်နဲ့ ငရုတ်သီးမပါတဲ့ တုံယမ်းပုစွန် ဟင်းရည် မှာခဲ့ပါတယ်။ အစားအသောက် အရမ်းအရသာရှိပြီး စုစုပေါင်း ၁၄၀ ဘတ် ကျပါတယ်။ ညနေပိုင်းမှာ ဆေးဆိုင်သွားပြီး ချောင်းဆိုးပျောက်ဆေး ဝယ်ချင်ပါတယ်။ မနက်ဖြန် စနေနေ့က ပိတ်ရက်ဖြစ်လို့ ည ၁၀ နာရီမှာ အိပ်ရာဝင်ပါမယ်။

အဖြေ (၂.၁) ထိုင်းသို့ ဘာသာပြန်များ:

  1. ၂၇၅ = สองร้อยเจ็ดสิบห้า
  2. နေ့လည် ၁ နာရီ = บ่ายโมง
  3. ည ၉ နာရီ = สามทุ่ม
  4. ဒီနေ့ ငါ မအားဘူး၊ အလုပ် အရမ်းရှုပ်တယ်။ = วันนี้ฉันไม่ว่าง ยุ่งมาก
  5. ကြက်ဆီထမင်း တစ်ပန်းကန်နဲ့ ရေတစ်ခွက် ပေးပါ။ = ขอข้าวมันไก่หนึ่งจานและน้ำเปล่าหนึ่งแก้ว
  6. ဒီအင်္ကျီ အရမ်းဈေးကြီးတယ်၊ လျှော့ပေးလို့ ရမလား။ = เสื้อตัวนี้แพงมาก ลดได้ไหม
  7. နင် ဘာအရောင် အကြိုက်ဆုံးလဲ။ = คุณชอบสีอะไรที่สุด
  8. မနေ့က သွားကိုက်လို့ ဆေးဆိုင်သွားခဲ့တယ်။ = เมื่อวานปวดฟัน เลยไปร้านขายยา
  9. နက်ဖြန် ပိတ်ရက် မဟုတ်လား။ = พรุ่งนี้วันหยุดไม่ใช่ไหม
  10. သန့်စင်ခန်း ဘယ်နားမှာလဲ။ = ห้องน้ำอยู่ที่ไหน

အဖြေ (၂.၂) ကွက်လပ်ဖြည့် အဖြေများ:

  1. ตื่น (ตื่นนอน)
  2. ชาม (ก๋วยเตี๋ยว)
  3. เสาร์
  4. อร่อย
  5. เจ็บ (เจ็บคอ)
